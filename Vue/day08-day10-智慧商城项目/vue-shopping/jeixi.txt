智慧商城项目代码解析
项目概述
这是一个基于 Vue 2.6.14 构建的智慧商城项目，采用了现代化的前端技术栈，包括 Vue Router 用于路由管理、Vuex 用于状态管理、Vant UI 组件库提供界面组件，以及 Less 预处理器用于样式编写。

路由配置 (router/index.js)
配置了项目的路由结构，包括权限控制。


javascript
Apply
import Vue from 'vue'
import VueRouter from 'vue-router'
import Login from '@/views/login'
import Layout from '@/views/layout'
import Search from '@/views/search'
import SearchList from '@/views/search/list'
import ProDetail from '@/views/prodetail'
import Pay from '@/views/pay'
import MyOrder from '@/views/myorder'

import Home from '@/views/layout/home'
import Category from '@/views/layout/category'
import Cart from '@/views/layout/cart'
import User from '@/views/layout/user'

import store from '@/store'

Vue.use(VueRouter)

const router = new VueRouter({
  routes: [
    { path: '/login', component: Login },
    {
      path: '/',
      component: Layout,
      redirect: '/home',
      children: [
        { path: '/home', component: Home },      // 首页
        { path: '/category', component: Category },  // 分类页
        { path: '/cart', component: Cart },      // 购物车
        { path: '/user', component: User }       // 个人中心
      ]
    },
    { path: '/search', component: Search },     // 搜索页
    { path: '/searchlist', component: SearchList },  // 搜索结果页
    { path: '/prodetail/:id', component: ProDetail },  // 商品详情页
    { path: '/pay', component: Pay },           // 支付页
    { path: '/myorder', component: MyOrder }    // 订单页
  ]
})

// 权限控制：定义需要登录才能访问的页面
const authUrls = ['/pay', '/myorder']

router.beforeEach((to, from, next) => {
  if (!authUrls.includes(to.path)) {
    // 非权限页面，直接放行
    next()
    return
  }

  // 是权限页面，需要判断token
  const token = store.getters.token
  if (token) {
    next()
  } else {
    next('/login')  // 未登录则跳转到登录页
  }
})

export default router
状态管理 (store/index.js)
采用模块化的方式管理状态，分为用户模块和购物车模块。


javascript
Apply
import Vue from 'vue'
import Vuex from 'vuex'
import user from './modules/user'   // 用户模块
import cart from './modules/cart'   // 购物车模块

Vue.use(Vuex)

export default new Vuex.Store({
  getters: {
    token (state) {
      return state.user.userInfo.token  // 获取token的快捷访问
    }
  },
  modules: {
    user,
    cart
  }
})

样式设计
项目使用 Less 预处理器编写样式，包含全局样式文件 styles/common.less，并通过 postcss-px-to-viewport 插件将像素单位转换为视口单位，实现响应式设计。

权限管理
项目实现了基于 Token 的权限管理机制：

在路由配置中定义了需要权限访问的页面
使用路由守卫拦截请求，检查用户是否登录
未登录用户将被重定向到登录页面
总结
这个智慧商城项目采用了现代化的前端技术栈和架构设计，具有以下特点：

模块化设计：代码按功能模块划分，便于维护和扩展
组件化开发：使用 Vant UI 组件库和自定义组件，提高开发效率
响应式布局：使用视口单位实现适配各种屏幕尺寸
权限控制：基于 Token 的权限管理机制
状态管理：使用 Vuex 集中管理应用状态
API 分层：按功能模块划分 API 接口，提高代码可维护性
项目结构清晰，代码组织合理，是一个典型的 Vue 商城项目实现。
